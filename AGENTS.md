# AGENTS.md

## Project status
This is a new project. The architecture and stack should be decided deliberately.

## Working rules
- Before implementing a large feature, first propose a plan.
- Do not add production dependencies without explaining why.
- Prefer small, reviewable commits.
- Do not read, print, modify, or commit secrets.
- Do not create unnecessary abstractions.
- Do not use destructive git commands unless explicitly asked.

## Development process
- Keep changes minimal and scoped.
- After making changes, summarize:
  1. changed files
  2. commands run
  3. tests passed/failed/not run
  4. risks and next steps

## Done means
- The project can be installed and run from a clean checkout.
- Basic README instructions are accurate.
- Basic tests exist once there is meaningful logic.
