# Security Policy

## Supported versions

ADB TV has not published a stable release. Security fixes are currently applied to the latest code on the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting flow from the repository's **Security** tab and select **Report a vulnerability**. Include:

- the affected commit or build;
- iOS and Android or Android TV versions;
- the network and pairing mode involved;
- reproducible steps and expected impact;
- relevant diagnostics with tokens, keys, device identifiers, and personal data removed.

Public disclosure should wait until a fix or mitigation is available.
