# ADB TV 0.9.0 Plan

Status: Planning

## Release Intent

Let a user disable an unwanted Preinstalled App that consumes resources and
later restore it. Keep the workflow within the existing Apps area.

`0.9.0` remains one cohesive feature release rather than a collection of
unrelated tools or broad maintenance work.

## Scope Boundary

- Manage complete Preinstalled App packages.
- Preserve disabled packages so the user can enable them again.
- Do not expose Android receiver, service, provider, or activity component
  controls.
- Do not claim that ADB TV can determine whether every OEM package is safe to
  disable.

## Decisions Pending

- Which Preinstalled Apps are eligible and which packages ADB TV must protect.
- Confirmation, recovery, and failure behavior.
- How enabled and disabled states are loaded and presented.
- Android-version and OEM compatibility boundaries.
- Automated and physical validation requirements.
