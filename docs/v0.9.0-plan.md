# ADB TV 0.9.0 Plan

Status: Planning

## Release Intent

Deliver one cohesive new user workflow. Do not turn `0.9.0` into a collection
of unrelated tools or combine the feature with broad maintenance work.

## Decisions Pending

- The single user outcome that defines the release.
- Workflow entry point and completion state.
- Data, permission, compatibility, cancellation, and failure boundaries.
- Automated and physical validation requirements.
