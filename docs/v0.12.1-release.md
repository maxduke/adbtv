# ADB TV 0.12.1

Version: `0.12.1` (build `21`). This maintenance release includes the fixes and
optimizations merged in [PR #57](https://github.com/maxduke/adbtv/pull/57).

## Changes

- Use the same endpoint identity for saved-device additions, connection repair,
  and configuration backup/restore. Equivalent Bonjour names/domains no longer
  create new duplicate devices because of case, domain dots, or local interfaces.
  Existing TV IDs, names, and Quick Launch favorites are preserved.
- Reuse file-list search and sorting results across transfer progress and other
  unrelated updates. Recompute rows when folder contents, search, sorting, or
  locale change, retaining folders-first ordering and distinct empty/error states.
- Filter app rows once per presentation and index Active Apps by package when
  snapshots change, preserving the originating TV and Android user.
- Isolate app-detail task ownership and reject cancelled or replaced requests'
  late pages, failures, and completion. Split existing root-view components into
  focused files while retaining their layout and navigation.
- Add 17 regression tests for endpoint identity, list invalidation, and task
  cancellation/replacement. No new features or production dependencies.

## Verification and remaining limits

- The application code passed 414 portable tests, native SwiftPM/iOS CI,
  unsigned Release IPA checks, and inspection of 320 English/Chinese simulator
  screenshots on iPhone/iPad in light/dark and normal/largest text sizes.
- Release preparation changes only version/build metadata, the README version,
  and this record. Required native CI runs for the release PR and merged commit;
  packaging and downloaded-asset checks are repeated for the immutable tag.
- Historical ambiguous device records are not merged or deleted automatically.
  Backup still rejects those records without changing saved data; resolve
  existing duplicates before exporting. The endpoint fix prevents new equivalent
  records through normal addition and connection repair.
- The user reported phone smoke testing with no apparent problems for v0.12.0.
  The full physical-device matrix has not been repeated for this maintenance
  patch. VoiceOver, physical input/Files-provider behavior, Android 8/10 device
  regressions, and iOS 17 compatibility checks remain tracked in
  [the hardware checklist](./hardware-test-checklist.md).
  Screenshots and portable tests do not establish those results.
- No iPhone Release performance profile has been collected, so this release
  makes no quantitative frame-rate or hardware compatibility claim.

## Installation

Download `ADBTV-unsigned.ipa` and its `.sha256` sidecar. Verify the checksum,
then sign the IPA with your own valid Apple certificate and provisioning profile.
iOS 17 or later is required. Default unsigned builds use manual host/port entry;
Bonjour discovery and QR pairing remain disabled without Apple's approved
Multicast Networking entitlement and matching signing configuration.

Full change history: <https://github.com/maxduke/adbtv/compare/v0.12.0...v0.12.1>.
