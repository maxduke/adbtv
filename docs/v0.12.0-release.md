# ADB TV 0.12.0

Version: `0.12.0` (build `20`). This release packages the changes merged since
`v0.11.0`; it adds no further application behavior or production dependency.

## Changes

- Add per-TV, per-Android-user Quick Launch favorites, with up to six apps,
  reordering, removal, and checked launching from Remote.
- Add English and Simplified Chinese UI, permission descriptions, status
  messages, and accessibility labels. Improve large-text layouts, contrast,
  connection recovery, and app loading/error states.
- Add local file search and sorting, plus sequential uploads of up to 100
  files with per-file conflict decisions, cancellation, and partial results.
- Add JSON backup and restore for saved TV connections and Quick Launch pins.
  Preview and select new devices before restoring; skip existing devices
  without replacing their names, connections, or favorites. Backups exclude
  ADB identity keys, pairing credentials, passwords, and TV app data.
- Bind installed-app snapshots and actions to the Android user. Keep uninstall
  scoped to that user and recheck user/package eligibility before acting.
- Fix checked shell exit reporting, upload replacement and cleanup handling,
  operation cancellation/timeouts, and installed-app metadata loading beyond
  the first 128 packages.
- Update GitHub Actions dependencies while retaining full commit SHA pins.

## Verification and limits

- The release metadata changes only the Xcode version/build, README version,
  and this release record. Required SwiftPM tests and the iOS simulator build
  run through the release PR and again on the merged commit.
- The immutable release tag builds a fresh unsigned IPA. Before publication,
  verify the downloaded asset's SHA-256, ZIP integrity, embedded version/build,
  app resources, and complete license notices against that tag.
- The latest application implementation passed 397 portable tests, native
  SwiftPM/iOS CI, IPA packaging, and inspection of 104 English/Chinese backup
  screenshots across iPhone/iPad, light/dark, and normal/largest text sizes.
  Earlier feature PRs recorded their own focused layout checks.
- Physical-device acceptance has not been repeated for this release. Files
  provider import/export and cancellation, real TV pairing/reconnect, Android
  8/10 regressions, VoiceOver, touch/keyboard interaction, and the iOS 17
  compatibility paths remain manual checks in
  [the hardware checklist](./hardware-test-checklist.md). Automated tests and
  deterministic screenshots do not establish those results. No additional
  hardware compatibility claim is made by this release.
- Backup restore is additive and does not restore pairing trust or merge
  favorites into existing devices. Reconnect to the original TV and pair again
  when required. Backups contain device addresses and app names; keep them private.

## Installation

Download `ADBTV-unsigned.ipa` and `ADBTV-unsigned.ipa.sha256` from this release.
Verify the checksum, then sign the IPA using your own valid Apple certificate
and provisioning profile. iOS 17 or later is required.

Default self-signed builds use manual host/port entry. Automatic Bonjour
discovery and QR pairing require Apple's approved Multicast Networking
entitlement and matching signing configuration; they remain disabled in the
default unsigned build.
