# ADB TV 0.8.2 Plan

Status: In progress

## Objective

Polish ADB Shell command submission without changing the Tools navigation or
adding persistent shell history.

## Confirmed Scope

- Clear the editable command after a valid submission is accepted.
- Keep the submitted command visible with its running, completed, cancelled, or
  failed result.
- Reflow the device and ADB Shell headers at accessibility Dynamic Type sizes
  and prevent the iOS back label from colliding with the device title.
- Preserve the existing command and output limits, timeout, cancellation,
  checked exit status, read-only presets, and non-persistent session state.
- Keep the existing Tools layout and production dependencies unchanged unless
  validation exposes a concrete defect.
- Set version `0.8.2` and increment the build number to `14`.

## Validation

- Add focused state coverage for submitted-command retention and device changes.
- Run Swift package tests and the iOS simulator build.
- Capture the existing Tools snapshots at default and maximum Dynamic Type,
  checking the surrounding layout as well as the Shell header.
- Package an unsigned IPA for physical verification.
- On physical iOS hardware, submit from both the keyboard **Send** action and
  the play button; confirm each command runs once, the editor clears, and the
  submitted command remains visible with its result.

## Out of Scope

- Persistent or session command history.
- An interactive terminal, streaming output, or multiple concurrent commands.
- New shell presets, customizable commands, or a Tools redesign.
