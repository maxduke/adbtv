# ADB TV 0.11.0 Plan

Status: Automated and physical validation complete

## Release Intent

Complete the existing app-management workflow with two focused recovery
actions: open Android's native App Info screen on the TV and clear a
User-installed App's data without uninstalling it.

## Scope

- Add Open App Settings on TV for user and system apps.
- Add Clear App Data for User-installed Apps only.
- Keep both actions inside the existing App Details sheet.
- Resolve the active numeric Android user immediately before each action.
- Require no Android Helper changes and no new production dependencies.
- Preserve Android 8.0 and Android 10.0 compatibility.

Do not add cache-only clearing. Android 8.0 and Android 10.0 expose no reliable
per-app shell command for it; users can use the native App Info screen when the
TV firmware provides that control.

## User Experience

Add a compact App Maintenance section below app information and system controls:

- Open App Settings on TV is a normal action for every installed app.
- Clear App Data is a destructive action for User-installed Apps only.
- Clear App Data requires confirmation naming the app and package.
- The confirmation states that accounts, settings, downloads, and other app
  data are permanently removed while the app remains installed.
- Dismiss App Details when either action starts so the existing Apps progress,
  cancellation, success, and error presentation remains visible.

Do not add row menus, swipe actions, a separate maintenance screen, explanatory
cards, batch controls, or operation history.

## Native Android Operations

### Open App Settings on TV

1. Resolve and validate the active numeric user.
2. Confirm that the package remains installed for that user.
3. Run a checked, bounded activity launch:

```sh
am start --user <user-id> -W \
  -a android.settings.APPLICATION_DETAILS_SETTINGS \
  -d package:<package>
```

Report success only when the checked shell command succeeds.

### Clear App Data

1. Resolve and validate the active numeric user.
2. Confirm that the package remains a User-installed App for that user.
3. Run:

```sh
pm clear --user <user-id> <package>
```

Require the validated command output to be exactly `Success`. On success, mark
cached helper details stopped and refresh Active Apps when that view initiated
the operation.

## Failure Behavior

- Reuse the existing installed-app operation timeout, cancellation, connection
  ownership, User Error, and Diagnostic Detail flow.
- Reject package disappearance, a user/system scope change, an active-user
  change before mutation, malformed output, nonzero exit, timeout, disconnect,
  or cancellation.
- Never report Clear App Data success from exit status alone.
- Do not retry either action automatically.
- Clear App Data is irreversible; cancellation can stop waiting but cannot undo
  a command Android already applied.

## Implementation

1. Extend `ADBTVInstalledAppManager` with package eligibility checks, Open App
   Settings, and Clear App Data.
2. Extend the existing installed-app command and result state in
   `ADBTVRootView`.
3. Add the compact App Maintenance section and Clear App Data confirmation to
   App Details.
4. Add focused core and presentation tests.
5. Update README guidance, hardware checks, version `0.11.0`, and build `19`.

Do not change navigation, app-list loading, Active Apps sampling, system-app
disable controls, file management, Android Helper, or dependencies.

## Automated Validation

- Verify exact numeric-user commands and package escaping.
- Verify Open App Settings accepts user and system packages.
- Verify Clear App Data rejects a package absent from the active user's
  third-party package list.
- Verify only exact `Success` is accepted.
- Cover command failure, active-user changes, package disappearance,
  cancellation, and timeout through existing shared paths.
- Cover user/system App Details action availability and confirmation content.
- Run Swift tests, iOS simulator build, UI snapshots, and unsigned IPA
  packaging.

## Physical Validation

On Android 8.0 and Android 10.0 hardware:

- Open App Settings for one user app and one system app; confirm the TV shows
  the matching native App Info screen.
- Cancel Clear App Data and confirm no data changes.
- Clear data for a disposable User-installed App, confirm it remains installed,
  becomes stopped, and launches into first-run state.
- Confirm Clear App Data is absent for system apps.
- Disconnect during each action and confirm ADB TV recovers without freezing or
  acting on another device.
- Repeat with the Android Helper absent.

## Out of Scope

- Per-app cache-only clearing.
- System-app data clearing.
- App backup or data export.
- Permission management.
- Component, service, receiver, job, or startup controls.
- Root, device-owner, or privileged-helper workflows.
